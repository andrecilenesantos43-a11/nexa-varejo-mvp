# Requisitos do MVP NexaVarejo

## Requisitos funcionais

- O sistema deverá permitir a interação do usuário com as funcionalidades principais do MVP.
- O sistema deverá armazenar e apresentar as informações necessárias para o funcionamento da solução.

## Requisitos não funcionais

- O sistema deverá possuir organização de código.
- O desenvolvimento deverá utilizar controle de versão.
- O projeto deverá permitir evolução contínua.

## Controle de qualidade

Serão aplicadas práticas de:
- Versionamento com GitHub;
- Testes automatizados;
- Integração contínua;
- Validação com usuários.
