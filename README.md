# NexaVarejo MVP

## Sobre o projeto

O NexaVarejo é um MVP desenvolvido na disciplina de Projeto de Software.

O objetivo é aplicar conceitos de Engenharia de Software durante o desenvolvimento de uma solução, utilizando boas práticas de versionamento, documentação, testes automatizados e integração contínua.

## Objetivos

- Desenvolver uma solução funcional baseada nos requisitos definidos.
- Aplicar controle de versão utilizando Git e GitHub.
- Organizar o desenvolvimento utilizando boas práticas de engenharia de software.
- Realizar testes e validações do sistema.
